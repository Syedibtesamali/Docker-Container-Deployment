# SWYNEX Task 3 — Containerization

## Overview
This project demonstrates how to package and run a simple Python application using Docker.

## Technologies
- Python 3.12
- Docker
- Git and GitHub

## Project Structure
```text
SWYNEX-Container/
├── app.py
├── Dockerfile
└── README.md
```

## Build the Docker Image
```bash
docker build -t swynex-task3 .
```

## Run the Container
```bash
docker run --rm swynex-task3
```

## Expected Output
```text
hello from SWYNEX Task 31
```

## What I Learned
- Creating a Dockerfile
- Building a Docker image
- Running a container
- Using Git and GitHub to manage project files
